# Project Context

## Purpose

Index konteks proyek yang perlu diketahui AI agar pekerjaan dapat dilanjutkan tanpa mengulang discovery dari nol.

## Active Projects

### TemplateKit

- Umbrella product/platform untuk template generation.
- Vertical/MVP pertama: Hook Generator.
- Repository teknis tetap menjadi source of truth untuk implementasi.
- Memory menyimpan konteks, keputusan, alasan, dan handoff.

### GilangDigital

- Digital business/store untuk eBook, e-course, dan template.
- Positioning dan detail produk harus mengikuti keputusan terbaru dari conversation memory.

### Other Projects

Project lain dapat ditambahkan di sini ketika menjadi aktif atau ketika konteksnya dibutuhkan untuk continuity.

## Project Entry Format

Untuk setiap project, simpan minimal:

- Purpose
- Current goal
- Current state
- Repository / canonical location
- Important decisions
- Constraints
- Pending work
- Next action
- Last verified date

## Rule

Jangan menganggap daftar ini sebagai pengganti repository proyek. Gunakan dokumen ini untuk memahami konteks sebelum membuka source code dan melanjutkan implementasi.
