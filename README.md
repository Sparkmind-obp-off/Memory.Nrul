# Memory.Nrul

Repository ini adalah **memory / continuity hub** untuk konteks percakapan dan keputusan yang perlu dibawa lintas sesi.

## Hubungan dengan TemplateKit

- **TemplateKit** tetap merupakan proyek digital utama yang sudah ada.
- Repository utama TemplateKit: https://github.com/Sparkmind-obp-off/TemplateKit
- **Hook Generator** adalah vertical/MVP pertama di dalam TemplateKit.
- `Memory.Nrul` tidak menggantikan repository TemplateKit; fungsinya sebagai tempat menyimpan konteks/continuity yang perlu dibawa ke sesi berikutnya.

## Aturan Continuity

Jangan mengulang tahap ideasi produk dari nol. Saat melanjutkan pekerjaan:

1. Baca memory/context yang relevan.
2. Periksa state repository TemplateKit yang aktual.
3. Tentukan satu micro-task konkret.
4. Implementasikan.
5. Test/verify.
6. Commit.
7. Push.
8. Berikan checkpoint singkat.

## Prinsip Kerja

`MICRO-TASK → IMPLEMENT → TEST → COMMIT → PUSH → CHECKPOINT → STOP`

Fokus utama: membangun aset nyata, publish, mendapatkan user, monetisasi, validasi, lalu improve dan scale.

## Catatan

Repository ini baru dibuat dan menjadi wadah continuity. Isi berikutnya dapat ditambahkan sebagai file memory/handoff terpisah tanpa mengganggu source code TemplateKit.
